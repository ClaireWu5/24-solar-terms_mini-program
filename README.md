# 廿四·候

> 每天一眼节气，给平淡日子一点仪式感，顺手晒给朋友看。

**「廿四·候」是一个给年轻人的「每日节气仪式感」微信小程序。**
每天早上或睡前打开，看一眼今天是哪个节气、第几候，配一张 AI 意境图和一句温暖絮语，心头一动，顺手生成一张美图发朋友圈。

## 我们为何而做

现代人的生活被屏幕填满，目光很少再投向窗外——柳树何时抽芽、蝉鸣哪天开始、第一片落叶落在哪里，这些看似日常的物候现象正在从我们的感知中消失。

一年四季流转得很快，但**那些被看见、被记住的瞬间，才是真正属于我们的时间**。

「廿四·候」想做的不是又一个科普工具，也不是一本电子节气词典，而是一次轻轻的提醒：**今天，也是独一无二的一天。**

## 核心闭环

```
每天打开 → 今日节气/候 + AI 意境图 + 今日絮语   （触动）
    ↓
一键生成分享图 → 发朋友圈                       （传播，朋友看到再进来）
    ↓
节气交替前收到订阅提醒 → 再次打开               （召回）
```

## 视觉：四季材质风格

每个季节一套材质与配色，节气按所属季节自动套用：

| 季 | 风格 | 底色 | 质感 | 主强调色 |
|---|---|---|---|---|
| 春 | D · 素绢柳芽绿 | `#E4EADB` | 绢丝织纹（经纬柔光 + 珠光晕） | 柳绿 `#7BA05B` |
| 夏 | A · 宣纸米 | `#EFEBE2` | 宣纸纤维（交错斜纹 + 微噪点） | 赭 `#C47A3A` |
| 秋 | C · 陶土 | `#EDE3D8` | 粗陶颗粒（磨砂哑光） | 陶褐 `#9B5E4A` |
| 冬 | B · 青瓷 | `#DCE2DA` | 冰裂纹开片（釉面高光） | 青瓷 `#5B7F6E` |

整体遵循国风、雅致、留白、纸墨感，参考传统书画"计白当黑、疏密有致"。

## 快速开始

```bash

# 4. 编译运行即可；未配置云环境时自动降级为内置静态节气表（2026-2027）
```

## 技术方案

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | 微信小程序原生 | 三 Tab：今日 / 廿四节气 / 我的 |
| 后端 | 微信云开发 | 云函数 + 云数据库 + 云存储，免服务器/域名/备案 |
| 天文算法 | `lunar-javascript` | 按太阳黄经实时计算节气，非死日期表（误差 ≤ 5 分钟） |
| AI 能力 | 预生成 | 意境图与絮语均离线生成、人工审核后入库，端上零调用 |
| 提醒 | 微信订阅消息 | 节气交替前推送 |

**为何"预生成"**：AI 用来放大"心头一动"，但不承担实时调用成本。生成动作发生在运营侧，用户端只读库——零延迟、成本可控、体验最稳。
